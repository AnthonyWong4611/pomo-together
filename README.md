# Pomo Together

A real-time virtual study room where users can join as guests, customize an avatar, move around a shared room, chat, run pomodoro timers, and manage personal todos.

## Features
- Guest entry with display names
- Avatar customization with colors or image URLs
- Click-to-move study room avatars
- Real-time player movement using Socket.IO
- Online player list
- Room chat
- Pomodoro timer with shared player statuses
- Personal todo list saved locally

## Tech Stack
- React
- Vite
- Socket.IO
- Express
- Node.js
- CSS

## How to Run Locally
1. Clone the repo
2. Install dependencies
3. Start the backend
4. Start the frontend
